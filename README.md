# Netflix Movies and TV Shows EDA

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset using Python.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Analysis Performed
- Data Cleaning
- Missing Value Handling
- Exploratory Data Analysis
- Data Visualization
- Insights Report

## Visualizations
- Bar Chart
- Line Chart
- Histogram
- Pie Chart
- Genre Analysis
- Country Analysis
